# Encrypt persistent provider credentials

OpenRouter, Gemini, and Groq Provider Credentials persist across Chrome restarts as purpose-bound AES-256-GCM ciphertext in `chrome.storage.local`, unlocked by a non-exportable device key retained in IndexedDB and exposed as plaintext only through trusted extension contexts for active use. Decrypted session copies may live in `chrome.storage.session`; credentials are excluded from logs and diagnostics and can be revealed, validated, replaced, or removed by the user. Key fields remain masked by default and decrypt for display only after an explicit eye-button action; they remask when the field loses focus, its disclosure closes, or the side panel closes. All three credentials must validate for Provider Readiness. Configuration export includes them only through the explicit **Include secrets** option, and imported credentials return to an unvalidated state.
