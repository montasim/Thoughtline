# Require explicit, revocable AI-processing consent

Thoughtline requires one unchecked, affirmative AI Processing Consent before any Foreground AI Job can transmit content. Onboarding and Settings name OpenRouter, Gemini, and Groq, explain the ordered fallback, enumerate applicable content categories, and state that local workflows contact those providers under their current terms. The disclosure links current provider controls and states that free-tier data use, retention, and billing status are governed by the user's accounts. The stored consent remains versioned so a material scope change requires renewed agreement. Revocation immediately blocks new provider calls while preserving local editing, copying, History, settings, credentials, profile data, and learned preferences.
