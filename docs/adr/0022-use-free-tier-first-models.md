# Use free-tier-first models

Thoughtline routes every writing capability through curated, user-selectable zero-cost candidates. The default route is OpenRouter `google/gemma-4-31b-it:free`, Gemini `gemini-3.5-flash`, then Groq `openai/gpt-oss-120b`. The centralized model registry is the only source of selectable IDs, context allowances, output budgets, and structured-output mode; arbitrary IDs and OpenRouter paid variants are rejected. Gemma is the default because Thoughtline prioritizes multilingual writing, while local Zod validation and one repair attempt compensate for its JSON-mode-only OpenRouter endpoint. OpenRouter is mechanically restricted to current zero-priced `:free` variants. Direct Gemini and Groq calls are zero-cost only while the user keeps those accounts on confirmed free tiers; ordinary keys cannot prove billing status, so Thoughtline states that limitation and never claims an unconditional provider-account guarantee.
